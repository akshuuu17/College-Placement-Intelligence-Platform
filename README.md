# College Placement Intelligence Platform

## Overview

A Data Science and Machine Learning project developed using Python, Pandas, Scikit-learn, Matplotlib, and Streamlit.

## Features

* Dataset Analysis
* Data Cleaning
* Exploratory Data Analysis (EDA)
* Placement Prediction
* Interactive Streamlit Dashboard
* Student Search Module

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Streamlit

## Machine Learning Model

Random Forest Classifier

## Accuracy

79.07%
